# Web 管理系统

前端是 `frontend/` 下的 React 18 + TypeScript SPA。生产构建由 OpenResty/Nginx
托管，Python 服务只提供 `/api/`。

## 页面

| 路径 | 页面 | 权限 |
| --- | --- | --- |
| `/` | 实时态势图和敌对观察 | 认证关闭时公开，否则需登录 |
| `/dashboard` | 实时处置工作台 | 认证关闭时公开，否则需登录 |
| `/reports` | 历史来袭分析 | 登录用户 |
| `/account/keys` | 设备密钥列表 | 登录用户 |
| `/admin/users` | 用户管理 | 管理员 |
| `/admin/identity` | 已验证身份记录 | 管理员 |
| `/admin/whitelist` | 允许军团和用户角色白名单 | 管理员 |
| `/admin/audit` | 中文审计日志 | 管理员 |
| `/login` | 管理员密码和普通用户 EVE SSO 登录 | 未登录用户 |

`/account` 和兼容路由 `/account/security` 重定向到 `/account/keys`，`/admin` 重定向到
`/admin/users`。管理功能按职责拆分为独立页面，不在同一页面堆叠用户、身份和审计内容。

审计页支持按客户端、角色、用户或动作搜索，并按操作类别、时间范围和正常/异常状态
筛选，每页显示 20 条。页面每 15 秒增量刷新；客户端异常区域展示在线异常以及最近
24 小时内意外离线的客户端，主动停止和更早的历史离线不计入当前异常。

## 数据约束

- 态势图节点只显示监控在线状态和确认的敌对数量。
- 敌对观察列表不显示旧威胁分数字段。
- 来袭报表只统计服务端生成的敌对告警，不把友军、未知角色、心跳或 OCR 当前名单直接
  计为来袭。
- 所有用户统计必须来自已解析到真实 EVE 角色 ID 的记录。
- 人员研判中的“威胁度”、击毁和损失只显示 zKillboard 实际返回的数据；缺失时显示
  “暂无数据”，不得使用告警分数或占位值回填。
- zKillboard 统计只用于研判和排序，不参与敌我分类、告警生成或客户端上报确认。

## 工作台与来袭分析

- 工作台只读取 `/api/v1/bootstrap`，每 15 秒增量刷新实时状态，不再请求 7 天历史。
- 工作台展示当前敌对星系、最新告警事件和客户端监控覆盖，服务于当班人员实时监控。
- 来袭分析同时读取所选时间范围内的已验证敌对告警和精确波次生命周期。来袭波次以同一
  星系“敌对首次出现 → 全部清空”为边界，不再按固定 15 分钟切段；同时展示趋势、热点
  星系、人员跨星系活动和 zKillboard 统计。
- 最近告警记录展示所选时间范围内最新 12 条有效敌对告警，用于核对明细；它不是来袭
  波次列表，也不承担实时处置。
- 星图态势继续保持独立页面和现有交互，不承载历史分析内容。

## 组件体系

前端直接使用 `@arco-design/web-react` 作为组件库，并未引入 Arco Design Pro 脚手架。
管理页的按钮、表格、表单、输入、选择器、卡片、标签、弹窗、抽屉和下拉菜单统一使用
Arco 组件。星图 Canvas、ECharts 图表、路由链接和语义化表单保留专用实现，因为它们
不属于通用业务控件，强行替换不会改善一致性或可访问性。

## 全局显示主题

全局导航和登录页提供明暗主题切换入口。主题切换只影响显示层，不会重新加载页面、重置
当前路由，也不会清空筛选、详情抽屉或实时情报状态。

- 主题覆盖整个前端：页面背景、导航和卡片、星图 Canvas（网格、航线、节点和文字）、
  人员/威胁列表、详情面板、个人账号、系统管理，以及仪表盘和报表中的 ECharts 图表。
- Arco Design 组件通过 `arco-theme="dark"` 同步到暗色主题；自绘 Canvas 和 ECharts
  使用对应主题调色板，避免出现局部仍为亮色的区域。
- 当前选择保存在浏览器 `localStorage` 的 `eve-sentry-theme` 键中，值为 `light` 或
  `dark`。首次访问且没有保存值时跟随操作系统的 `prefers-color-scheme` 偏好。
- 主题仅是前端静态资源行为，不需要新增环境变量、后端配置、数据库迁移或部署步骤。

## 开发与构建

```powershell
cd frontend
npm ci
npm run dev
```

开发地址为 `http://127.0.0.1:5173`。测试与生产构建：

```powershell
npm test
npm run build
npm run preview
```

预览地址为 `http://127.0.0.1:4173`。生产代理必须让未知页面路径回退到
`index.html`，否则直接访问 `/reports` 或 `/admin/users` 会返回 404。

## 实时更新

星图态势读取 `/api/v1/bootstrap` 获取初始状态，通过 `/api/v1/events` SSE 接收后续
告警和节点变化。工作台按 15 秒重新读取 bootstrap 中对应的实时数据，不整页刷新。
来袭分析读取专用历史接口 `/api/v1/alert-history` 和 `/api/v1/hostile-waves`，两者均
显式限制为最多 1000 条；服务端普通历史列表默认最多返回 100 条。PostgreSQL 历史告警
按时间索引分页，只使用报告快照和本地缓存的身份资料，不触发实时 ESI/zKill 丰富，也不
改变 `/api/alerts` 与 SSE 的实时冷却语义。代理层必须为事件流关闭 buffering 和 cache，
并保留较长的读取超时。预警客户端不加载完整 Bootstrap，而是通过 SSE 精简快照恢复活跃
节点。

静态资源文件名带内容哈希，可以在 `/assets/` 配置长期缓存；`index.html` 不应使用
同样的 immutable 缓存策略，以免部署后继续引用旧资源。
