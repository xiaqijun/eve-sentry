# QQ 查询的人员资料补全

QQ 的人员、军团、联盟和所有节点查询使用现有 OCR 查询接口。客户端回传名单后，
服务端可能仍在异步解析人员身份和军团资料；OCR 查询完成仅代表客户端已回传，
不代表全部人员资料已补全。

对于需要展示人员归属的 QQ 查询，机器人在获得 OCR 结果后，最多额外等待 20 秒，
通过同一查询 ID 轮询现有结果，直到快照中的待解析人员完成补全。空名单、已经明确
无法识别的角色，以及已获得军团资料但没有联盟的角色不等待。若查询接口异常或等待
超时，返回最后一次可用结果并提示资料未能及时补全；不会把旧名单合入本次快照。
只展示姓名的星系名单查询和周期监控不增加等待。

此行为不修改服务端 HTTP 协议、OCR 快照的范围、主监控状态或计费记录。
