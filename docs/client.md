# 客户端操作指南

这份文档只介绍 Windows 客户端的界面操作。下载安装后，不需要配置 Python、OCR 模型或环境变量。

## 下载和启动

1. 下载[最新版 Windows 客户端](https://evesentrydownload.kisectool.com/download/latest)。
2. 解压整个压缩包，不要只复制其中的 EXE 文件。
3. 启动 `EVE-Sentry-Monitor.exe`。
4. 将 EVE Online 设为“窗口化”或“无边框窗口”模式，并保持游戏窗口未最小化。

首次运行时，Windows 如果显示安全提示，请确认文件来源后选择继续运行。

更新包下载并校验完成后，关闭客户端窗口会退出旧进程、覆盖当前解压目录并从同一路径
重新启动。即使启用了“关闭到托盘”，待安装更新也会优先完成安装；普通关闭仍进入托盘。

## 第一次使用

### 1. 连接服务端

在客户端左侧填写：

- **服务端**：管理员提供的服务器地址。
- **设备密钥（可选）**：需要客户端身份认证时从网页账号创建，或向管理员获取；通常以
  `eve_` 开头。留空时客户端不进行认证预检和身份扫描，也不发送 `Authorization` 请求头。

输入完成后点击界面其他位置。顶部连接状态显示正常后再继续操作。密钥为空时身份状态
显示 **未启用认证** 属于正常状态；服务端为 `enforce` 模式时仍需填写有效密钥。

### 2. 选择 EVE 窗口

1. 先登录 EVE，并打开本地频道成员列表。
2. 在 **目标窗口** 下拉框中选择一个角色窗口，用于区域校准和预览。
3. 点击 **监控窗口 N/M**，逐个勾选需要监控的客户端；菜单也支持 **全选** 和 **仅选当前窗口**。
4. 如果没有看到窗口，点击下拉框右侧的 **刷新窗口** 图标。
5. 依次在下拉框中切换窗口并点击 **选择区域**，框选各自的本地频道成员列表。
6. 点击 **预览**，确认当前窗口截图只包含需要识别的成员列表。

目标窗口下拉框只控制当前校准和预览对象，不会改变监控范围。客户端只记录当前在线且已勾选的窗口标题，并保留每个窗口的区域；窗口位置、大小或显示器缩放发生明显变化时，建议重新选择区域。多窗口监控会按角色分别读取本地频道日志，因此不同客户端可以处于不同星系。

监控窗口菜单按“角色 · 星系 · 状态”显示当前在线的客户端。游戏窗口关闭后会从菜单、状态缓存和已选择记录中移除，不再保留“未知”离线项；重新打开后，如果没有启用全选，需要重新勾选该窗口。按钮变为红色表示当前尚未选择任何在线窗口。

### 3. 开始监控和预警

- 点击 **开始监控**：只识别 **监控窗口 N/M** 菜单中已勾选的客户端。运行中改变勾选项时，监控线程会自动更新。
- 点击 **开启预警**：接收各监控节点的预警，在顶部浮窗显示并按设置播放声音。

这两个按钮互相独立：

- 只开启监控时，本机会上报信息，但不会显示预警浮窗。
- 只开启预警时，本机不会识别窗口，但仍可接收其他节点的预警。
- 需要完整功能时，请同时开启监控和预警。

## 界面说明

| 区域 | 用途 |
| --- | --- |
| 左侧设置 | 填写服务端，可选填写设备密钥，调整扫描间隔、窗口关键字及告警声音 |
| 顶部按钮 | 开始或停止监控，开启或关闭预警 |
| 目标窗口 | 选择校准窗口、勾选任意监控窗口、重新框选识别区域及查看预览 |
| 运行状态 | 查看服务端、身份、OCR、窗口和区域是否正常 |
| 窗口状态 | 分角色查看当前星系、窗口、区域、监控状态和最近动作 |
| 运行日志 | 查看连接、识别和上传过程；右上角按钮可清空日志 |

扫描间隔控制画面变化检测频率。画面无变化时客户端会跳过 OCR 以减少资源占用，但仍按
设定的扫描间隔继续截图检测，不会因为连续静态画面自动延长间隔。

### 告警声音

左侧可以：

- 开启或关闭 **告警声音**。
- 设置同一轮告警的 **播放间隔**。
- 设置同一轮告警的 **播放次数**。

顶部预警浮窗中，绿色表示安全，红色表示发现敌对目标；红色方框会显示当前人数。
浮窗可在 **列表** 和 **星图** 间切换。星图视图通过紧凑的账号按钮展开多选菜单，
不会常驻显示角色列表；可多选需要关注的在线角色，并选择显示其所在星系周围
`1`、`2`、`3` 或 `5` 跳。
绿色节点标记所选角色及所在星系，红色节点标记当前仍有敌对证据的预警星系。
客户端只请求所选角色附近的局部拓扑，不下载或绘制全量星图；角色换星系、预警出现或
清空时只更新浮窗对应数据。

## 日常使用

1. 启动并登录 EVE Online。
2. 启动 EVE Sentry。
3. 确认顶部连接状态和 **运行状态** 没有异常。
4. 确认各角色的识别区域正确，并在 **监控窗口 N/M** 中勾选本次需要监控的客户端。
5. 点击 **开始监控**。
6. 需要接收预警时，再点击 **开启预警**。

退出前可分别点击 **停止监控** 和 **关闭预警**。如果直接关闭客户端，也会停止本机监控。

## 更新客户端

客户端会自动检查新版本，也可以点击左下角的 **检查更新**。

发现新版本后，按界面提示下载并选择 **安装并重启**。更新期间不要手动移动或删除客户端目录；已配置的设备密钥和本地设置会保留。

从 `1.0.9` 起，已经校验完成的更新包会在客户端重启后继续保留，无需重新下载。安装前会检查压缩包、客户端目录写入权限和可用磁盘空间；检查失败时客户端不会退出，可以修复问题后重试。

从 `1.0.11` 起，各 EVE 窗口的识别区域保存在 `%LOCALAPPDATA%\EVE Sentry\region_prefs.json`，
客户端更新不会再覆盖该配置。首次启动会自动迁移安装目录或上一个版本备份中的旧配置；
已有用户目录配置时始终以用户目录为准。

安装器会备份当前版本，并在新客户端连续运行 8 秒且确认版本号后才删除备份。安装或启动检查失败时会自动恢复旧版本，并在下次启动显示结果。详细安装日志保存在 `%LOCALAPPDATA%\EVE Sentry\updates\update.log`。

## 常见问题

### 目标窗口为空

- 确认 EVE 已启动且已进入角色。
- 确认游戏不是全屏独占模式，也没有最小化。
- 点击 **刷新窗口**。
- 如果改过 **窗口关键字**，恢复默认值后重试。

### 预览区域不正确

点击 **选择区域** 重新框选成员列表。框选时尽量避开聊天正文、滚动条以外的按钮和其他窗口。

### 无法开始监控

依次查看 **运行状态** 中的服务端、身份、OCR、窗口和区域。密钥留空时显示 **未启用认证**
不是客户端故障；若服务端为 `enforce` 模式则需填写有效密钥。已填写但失效时，需要在
网页中重新创建密钥或联系管理员。

### 有红色预警但没有声音

确认左侧 **告警声音** 已开启、Windows 没有静音，并检查播放间隔和播放次数。

### 仍然无法解决

点击左下角 **导出诊断包**，把生成的文件和问题发生时间一起交给管理员。诊断包用于排查客户端状态，不需要手工复制运行日志。
