# 客户端操作指南

这份文档只介绍 Windows 客户端的界面操作。下载安装后，不需要配置 Python、OCR 模型或环境变量。

## 下载和启动

1. 下载[最新版 Windows 客户端](https://evesentrydownload.kisectool.com/download/latest)。
2. 解压整个压缩包，不要只复制其中的 EXE 文件。
3. 启动 `EVE-Sentry-Monitor.exe`。
4. 将 EVE Online 设为“窗口化”或“无边框窗口”模式，并保持游戏窗口未最小化。

首次运行时，Windows 如果显示安全提示，请确认文件来源后选择继续运行。

更新包下载并校验完成后，关闭客户端窗口会退出旧进程、覆盖当前解压目录并从同一路径
重新启动。即使启用了“关闭到托盘”，待安装更新也会优先完成安装；普通关闭仍进入托盘。

## 第一次使用

### 1. 连接服务端

在客户端左侧填写：

- **服务端**：管理员提供的服务器地址。客户端不内置默认地址，需要显式填写；留空时不会
  建立网络连接，可进行本地监控识别，但不会上传情报，也不能开启预警。
- **设备密钥（可选）**：需要客户端身份认证时从网页账号创建，或向管理员获取；通常以
  `eve_` 开头。留空时客户端不进行认证预检和身份扫描，也不发送 `Authorization` 请求头。

输入完成后点击界面其他位置。顶部连接状态显示正常后再继续操作。密钥为空时身份状态
显示 **未启用认证** 属于正常状态；服务端为 `enforce` 模式时仍需填写有效密钥。

### 2. 选择 EVE 窗口

1. 先登录 EVE，并打开本地频道成员列表。
2. 在 **目标窗口** 下拉框中选择一个角色窗口，用于区域校准和预览。
3. 点击 **监控窗口 N/M**，逐个勾选需要监控的客户端；菜单也支持 **全选** 和 **仅选当前窗口**。
4. 如果没有看到窗口，点击下拉框右侧的 **刷新窗口** 图标。
5. 依次在下拉框中切换窗口并点击 **选择区域**，框选各自的本地频道成员列表。
6. 点击 **预览**，确认当前窗口截图只包含需要识别的成员列表。

目标窗口下拉框只控制当前校准和预览对象，不会改变监控范围。客户端只记录当前在线且已勾选的窗口标题，并保留每个窗口的区域；窗口位置、大小或显示器缩放发生明显变化时，建议重新选择区域。多窗口监控会按角色分别读取本地频道日志，因此不同客户端可以处于不同星系。

监控窗口菜单按“角色 · 星系 · 状态”显示当前在线的客户端。游戏窗口关闭后会从菜单、状态缓存和已选择记录中移除，不再保留“未知”离线项；重新打开后，如果没有启用全选，需要重新勾选该窗口。按钮变为红色表示当前尚未选择任何在线窗口。

### 3. 开始监控和预警

- 点击 **开始监控**：只识别 **监控窗口 N/M** 菜单中已勾选的客户端。运行中改变勾选项时，监控线程会自动更新。
- 点击 **开启预警**：接收各监控节点的预警，在顶部浮窗显示并按设置播放声音。

监控使用后台窗口捕获，不会在 EVE 窗口周围显示 Windows Graphics Capture 的黄色边框。

客户端会在执行启动动作前检查前置条件：监控必须至少选择一个当前在线的 EVE 窗口，
并且每个已选窗口都要有成员列表区域。条件不满足时只提示原因，不会进入身份验证或启动
识别线程；修正后再次点击即可。**全选当前在线窗口** 只选择本次已发现的窗口，之后新上线
的窗口不会被静默加入，避免误监控。

开启预警前必须填写服务端地址。地址输入错误时输入框会标红并保留修改内容，修正为有效的
`http://` 或 `https://` 地址后再试；清空地址会关闭服务端通信。认证正在进行时取消按钮，
认证完成后不会重新开启已取消的功能。

这两个按钮互相独立：

- 只开启监控时，本机会上报信息，但不会显示预警浮窗。
- 只开启预警时，本机不会识别窗口，但仍可接收其他节点的预警。

填写设备密钥后，客户端会自动从 EVE 日志发现角色身份，不需要手动开启 Listener 扫描。
扫描按中英文 Local 日志文件名末尾的角色 ID 分组，只处理每个角色修改时间最新的一份，
并向服务端上报 ID，不回放全部历史。带 ID 的日志不会读取文件正文；只有缺少末尾 ID 的
旧格式日志才读取 `Listener` 文件头进行兼容。设备密钥为空时不会执行身份扫描。
- 需要完整功能时，请同时开启监控和预警。

## 界面说明

| 区域 | 用途 |
| --- | --- |
| 左侧设置 | 填写服务端，可选填写设备密钥，调整扫描间隔、窗口关键字及告警声音 |
| 顶部按钮 | 开始或停止监控，开启或关闭预警 |
| 目标窗口 | 选择校准窗口、勾选任意监控窗口、重新框选识别区域及查看预览 |
| 运行状态 | 查看服务端、身份、OCR、窗口和区域是否正常 |
| 窗口状态 | 分角色查看当前星系、窗口、区域、监控状态和最近动作 |
| 运行日志 | 查看连接、识别和上传过程；右上角按钮可清空日志 |

监控线程会单独检测每个 EVE 窗口的采集连接：窗口明确关闭会立即标记为掉线，后台画面连续
三次不可用才会标记为掉线，避免单帧采集抖动误报。下一次成功采集会标记为已恢复，并立即
刷新客户端心跳。心跳的 `details.targets` 会在有状态信息时包含 `capture_online` 和
`capture_failure_count`；`capture_offline_count` 表示当前掉线的监控窗口数量。掉线不会清除
窗口选择，窗口重新出现后仍按原选择策略重连。

客户端还会读取 EVE `logs/Gamelogs` 中每个最新日志实例的尾部，用于识别游戏进程仍存在但
已与 EVE 服务器断开的情况。中文和英文断线文本都会触发 `game_connection_online=false`，
连接恢复文本会恢复为 `true`；日志文件按文件名实例 ID 与角色/客户端 ID 绑定，多开窗口
不会共用一个断线状态。初次发现日志只读取最新文件的有限尾部，不扫描或回放整个历史目录；
文件没有变化时不会重复读取。心跳目标会额外携带 `game_connection_log_id` 和
`game_connection_last_event_at`，服务端和预警端会暂时隐藏游戏连接已断开的目标。

扫描间隔控制画面变化检测频率。画面无变化时客户端会跳过 OCR 以减少资源占用，但仍按
设定的扫描间隔继续截图检测，不会因为连续静态画面自动延长间隔。

### 告警声音

左侧可以：

- 开启或关闭 **告警声音**。
- 在 **告警声音文件** 中点击 **选择...**，选择自定义 WAV 音频；清空路径即可恢复使用内置声音。
- 使用 **音量** 滑块调整告警声音大小，右侧会显示当前百分比。
- 在 **播放方式** 中选择 **持续响** 或 **按间隔响**。持续响会在仍有敌对目标时循环播放，
  直到该星系恢复安全；按间隔响会按下面的播放间隔和次数播放。
- 设置同一轮告警的 **播放间隔**。
- 设置同一轮告警的 **播放次数**。

播放间隔和播放次数只影响 **按间隔响** 模式；切换为 **持续响** 后，这两个数值会保留，
切回按间隔响时继续生效。自定义声音目前支持 WAV 文件；文件不存在、无法读取或未设置时，
客户端会自动回退到内置告警声音。告警声音设置会保存到本地配置，客户端重启后仍然保留。

顶部预警浮窗中，绿色表示安全，红色表示发现敌对目标；红色方框会显示当前红色敌对图标数量。
红色图标是预警的唯一依据，OCR 姓名识别只补充角色、军团、联盟等信息，关闭 OCR 不会影响
预警触发或数量上报。
红色数量或名单区域发生变化时才对完整成员列表执行 OCR；客户端上传完整 OCR 名单，只过滤行首的 UI
图标噪声，不按敌我清洗，也不上传文字框或红色图标坐标。服务端收到名单后逐名通过 ESI 校验并分类，
红色图标数量单独作为视觉证据。
完整 OCR 成功后不会继续消耗补偿
帧，只有空结果才有限重试。姓名区域指纹会忽略背景变化和图标边界的轻微像素抖动，避免
稳定名单重复执行 OCR。
稳定画面和清空状态不会重复 OCR，距离等非姓名区域变化也不会触发识别。
浮窗可在 **列表** 和 **星图** 间切换。星图视图通过紧凑的账号按钮展开多选菜单，
不会常驻显示角色列表；可多选需要关注的在线角色，并选择显示其所在星系周围
`1`、`2`、`3` 或 `5` 跳。
绿色节点标记所选角色及所在星系，红色节点标记当前仍有红色敌对图标的预警星系。角色从一个
星系跳到另一个星系后，客户端会清除旧星系并强制刷新新星系的当前数量，即使前后数量相同也
不会残留旧的红色节点。
客户端只请求所选角色附近的局部拓扑，不下载或绘制全量星图；角色换星系、预警出现或
清空时只更新浮窗对应数据。

监控窗口菜单支持运行中增量调整。新增窗口只创建并启动对应的监控线程，取消选择或窗口
下线时只停止对应线程，其他窗口的线程、扫描进度和 OCR 调度器保持不变，不会触发全量重连。

## 日常使用

1. 启动并登录 EVE Online。
2. 启动 EVE Sentry。
3. 确认顶部连接状态和 **运行状态** 没有异常。
4. 在目标窗口下拉框和 **监控窗口 N/M** 菜单中手动选择窗口；客户端启动后默认不勾选任何窗口。
5. 依次选择每个窗口的 **选择区域** 并框选成员列表；未选择窗口或区域时，点击开始监控会提示并不会启动 OCR。
6. 点击 **开始监控**。
7. 需要接收预警时，再点击 **开启预警**。

退出前可分别点击 **停止监控** 和 **关闭预警**。如果直接关闭客户端，也会停止本机监控。

## 更新客户端

客户端会自动检查新版本，也可以点击左下角的 **检查更新**。

发现新版本后，按界面提示下载并选择 **安装并重启**。更新期间不要手动移动或删除客户端目录；已配置的设备密钥和本地设置会保留。

从 `1.0.9` 起，已经校验完成的更新包会在客户端重启后继续保留，无需重新下载。安装前会检查压缩包、客户端目录写入权限和可用磁盘空间；检查失败时客户端不会退出，可以修复问题后重试。

从 `1.0.11` 起，各 EVE 窗口的识别区域保存在 `%LOCALAPPDATA%\EVE Sentry\region_prefs.json`，
客户端更新不会再覆盖该配置。首次启动会自动迁移安装目录或上一个版本备份中的旧配置；
已有用户目录配置时始终以用户目录为准。

安装器会备份当前版本，并在新客户端连续运行 8 秒且确认版本号后才删除备份。安装或启动检查失败时会自动恢复旧版本，并在下次启动显示结果。详细安装日志保存在 `%LOCALAPPDATA%\EVE Sentry\updates\update.log`。

## 常见问题

### 目标窗口为空

- 确认 EVE 已启动且已进入角色。
- 确认游戏不是全屏独占模式，也没有最小化。
- 点击 **刷新窗口**。
- 如果改过 **窗口关键字**，恢复默认值后重试。

### 预览区域不正确

点击 **选择区域** 重新框选成员列表。框选时尽量避开聊天正文、滚动条以外的按钮和其他窗口。

### 无法开始监控

依次查看 **运行状态** 中的服务端、身份、OCR、窗口和区域。密钥留空时显示 **未启用认证**
不是客户端故障；若服务端为 `enforce` 模式则需填写有效密钥。已填写但失效时，需要在
网页中重新创建密钥或联系管理员。

### 有红色预警但没有声音

确认左侧 **告警声音** 已开启、Windows 没有静音，并检查播放间隔和播放次数。

### 仍然无法解决

点击左下角 **导出诊断包**，把生成的文件和问题发生时间一起交给管理员。诊断包用于排查客户端状态，不需要手工复制运行日志。
