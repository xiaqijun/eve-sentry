# 1.0.76 预警 ACK 能力发布

2026-10-02 发布客户端 `1.0.76`，包含当前主分支的收费预警 ACK 协议兼容能力。

## 改动

- 预警客户端声明 `alert-ack.v1` 能力和连接 ID，并在界面确认收到带完整服务端绑定证据的预警后发送幂等 ACK。
- ACK 只接受服务端提供的 `delivery_id`、事件修订、连接和时间区间，不会把普通免费预警推算成收费区间。
- ACK 失败会保留在客户端队列，在后续心跳或重连时安全重试；服务端幂等键保证重复提交不会重复结算。
- 保持现有 SSE 游标、重连和普通心跳行为不变。

## 发布边界

本版本来自单体仓库 `main`，由 `Client CI` 通过后自动进入受保护的 `client-release` 环境。
服务端当前版本不随客户端发布重新部署；客户端发布脚本会生成监控客户端、频道客户端、模型包、
签名清单和源码元数据，并更新下载站的 `latest.json`。
