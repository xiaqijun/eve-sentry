# 1.0.75 Seat 客户端认证兼容修复

2026-09-30 发布客户端认证兼容修复，服务端和客户端代码均来自当前单体仓库。

## 改动

- 频道日志客户端不再把管理端 `/api/v1/auth/me` 当作 Seat key 验证接口。
- 客户端启动后通过已有的客户端心跳接口验证密钥，并继续使用心跳上报运行状态。
- 服务端保留旧客户端对 `/api/v1/auth/me` 的只读兼容访问，并继续兼容已废弃的身份校验请求；
  不读取 EVE 身份、不调用 ESI、不创建身份任务。

## 验证

- 客户端频道相关测试：14 项通过。
- 服务端 HTTP 测试：143 项通过，3 项跳过。
- GitHub Client CI、Contract Compatibility 和服务端部署门禁通过后，再生成客户端安装包。

## 发布边界

客户端版本递增到 1.0.75，避免覆盖已经存在的 1.0.73 Release，也保留已取消的 1.0.74
历史台账。安装 1.0.75 后，频道日志客户端启动不会再请求 `/api/v1/auth/me`。
