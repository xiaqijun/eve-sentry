# 1.0.72 联动发布记录

本记录随发布候选提交；“本地验证”不代表生产已部署。最终以 GitHub 工作流、Release 签名清单和运行检查为准。

## 交付范围

- 客户端：逐窗口采集会话、帧序号、同帧 OCR 证据；停止/离开与视觉清空区分；启动不重放停用期事件；
  统一状态模式下本地裸人数不覆盖服务器选择；未知状态显示“上次”，内容不变不重排浮窗。
- 服务端：按连续驻留选单主、截断接管；星系当前状态和事件同事务；独立过期维护、失败写入修复、查询隔离。
- 档案与组织关系：长期档案批量处理、官方剩余期限、分级后台刷新；独立军团/联盟来源快照；无个人声望例外；
  同军团/有效联盟按 ID 识别、显式零关系保留、失败不当空表、授权切换隔离；管理配置无需手动重启。
- ESI 路线：114 共享连接与预算，47 固定目标 TLS 透传；受保护的分阶段切换及回滚，不删除旧缓存。
- 前端/QQ：消费同一当前状态、未知状态不重复通知、名单采用最新人数；更新设计、API、介绍和唯一客户端指南入口。

## 发布顺序与回滚

推送 main 后等待服务端、机器人、Gateway、Client CI/客户端发布、协议和下载站工作流完成。

组织规则先 shadow 比较，再 on；档案模式与网络模式独立。
客户端回滚使用此前签名版本；服务器回滚既有部署备份。数据库新增表保留，不做破坏性降级。
